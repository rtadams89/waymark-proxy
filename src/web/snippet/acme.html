Domain Name Server: If you have more than one DNS server, enter them separated by commas (e.g. ns1.example.com,ns2.example.com). Used for DNS-01 challenge propagation verification.
Recursive NSs Propagation Check: Verify the TXT record has propagated to all specified DNS servers before proceeding. If no DNS servers are configured above, falls back to 8.8.8.8, 8.8.4.4, 1.1.1.1, 1.0.0.1. Required for CAs using MPIC (Multi-Perspective Issuance Corroboration). May take longer than the default 600s timeout — increase propagation timeout if needed. Leave disabled unless required.
Authoritative NSs Propagation Check: Query authoritative nameservers directly during DNS-01 propagation verification. Disable this if direct outbound DNS traffic to Internet nameservers is blocked and all DNS resolution is handled through an internal recursive resolver. When disabled, Recursive NSs Propagation Check is automatically enabled to ensure at least one propagation check remains active.
