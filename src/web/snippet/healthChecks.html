A disabled upstream gets no traffic. If every upstream of the rule is disabled, visitors get the "Web server is down" (521) error page until one passes its checks again.
Every enable and disable is written to Waymark's log with its reason, under [healthcheck].
Active checks also feed the Health & Uptime page (Monitoring): one entry per 5 minutes, marked down if the upstream was out of load balancing at any point in it. Rules without active checks are not shown there.
ICMP ping uses an unprivileged ping socket (allowed by default on Debian through net.ipv4.ping_group_range) and falls back to a raw socket.
If the same backend address is used by several rules, it is taken out of load balancing when any rule's checks find it unhealthy.
A disabled destination gets no new connections. If every destination of the proxy is disabled, new connections are closed until one passes its checks again. Open connections stay, unless "Close connections when a destination goes down" is on.
