Maintenance Mode
Rule:
Off. Requests are proxied as usual.
Leave empty for the default message.
minutes
Shown as "Expected back in about …" and sent as Retry-After, counting from when maintenance was turned on. 0 leaves it out.
Access rules, rate limits, CAPTCHA and authentication still apply first; the maintenance page replaces only the proxying.
Health checks keep running, so you can watch the destination come back on the Health Checks page and the Status page before turning maintenance off.
The HTTP Proxy list marks rules in maintenance with an orange wrench.
To use your own page, put a maintenance.html in the templates folder of Waymark's web root (default ./www/templates/). The placeholders {{message}}, {{retry}} and {{host}} are filled in.
