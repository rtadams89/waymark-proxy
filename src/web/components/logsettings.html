Logging

Where Waymark's system and access logs go, and how the log file is rotated. Read them on System > System Logs and Monitoring > Access Logs.

Where logs go

System logs are Waymark's own messages: startup, settings changes, certificate renewal, high availability, errors. Access logs have one line per HTTP request the proxy handles. Send each to the log file, to syslog servers, to both or to neither. System messages are also printed to standard output, so systemd's journal keeps them either way.

Log file (the log folder on this node; rotation below)
