Destination Requires TLS
Destination TLS Requirement

When you enable Destination requires TLS, it means the destination server (the server you are proxying to) requires a secure (HTTPS) connection.
This does not affect whether clients connect to this proxy rule using HTTP or HTTPS.

Example
Matching Keyword: mydomain.com
Target: example.com:443 (TLS enabled)
  • Client connects to mydomain.com (HTTP or HTTPS, depending on your proxy setup)
  • Proxy forwards requests to example.com:443 using HTTPS
Use this option if your destination server only accepts secure connections.
If your destination uses a self-signed certificate, check the Ignore TLS/SSL Verification Error option in Advanced Settings.
What are Sticky Sessions?
Sticky Sessions (Session Affinity)

Sticky session ensures that requests from the same client are always forwarded to the same destination server. This is useful for applications that store session data locally and require the client to consistently connect to the same backend.

How to Add Multiple Destinations
  • Go to Proxy Rules in the sidebar.
  • Click the edit button (⋮) of your proxy rule.
  • Open Destinations → Edit Destinations to add more destinations for load balancing.
Sticky sessions only matter when the rule has more than one destination.
