Listening Address

Address and port of this host to listen on, e.g. :25565 or 192.168.1.1:25565.



UDP Idle Timeout
How long a UDP client session is kept after its last packet. 0 uses 60 seconds. TCP connections stay open until either side closes them.

Compatibility

Send the client's address to the destination in a PROXY protocol header. Only turn this on if the destination expects it.
Proxy Protocol V1 is not supported for UDP. UDP packets are forwarded without the header.
