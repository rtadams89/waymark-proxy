What is a Layer 4 proxy?
TCP and UDP forwarding

A Layer 4 proxy forwards the raw TCP or UDP traffic, byte for byte, without reading it. Use it for services that do not speak HTTP, such as databases, game servers, SSH, mail or DNS.
For websites and web apps, use an HTTP proxy rule instead: it can serve certificates, route by host name and add headers.

How to add more destinations
Load balancing and failover
  • Go to Proxy Rules in the sidebar.
  • Click the edit button (⋮) of your rule.
  • Use Destinations → Edit Destinations to add more destination servers and set their weights (0 makes a destination a backup). Choose weighted or least connections balancing and sticky sessions under Destinations.
With health checks on, a destination that fails its checks gets no new connections until it passes again.
