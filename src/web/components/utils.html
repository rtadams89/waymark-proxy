Geo-IP Lookups

Resolves visitor IP addresses into countries for country rules in ACLs, visitor statistics and the status page's visitor map. On a proxy that only serves your own network, turning this off saves the memory the database uses and a lookup on every request.


While off, the database is not loaded, statistics record no visitor countries, and ACLs can't use countries. Address rules keep working.

Geo-IP Database Update

The Geo-IP database resolves visitor IP addresses into country codes for access control rules and statistics. Updating it keeps the country lookup results accurate.
