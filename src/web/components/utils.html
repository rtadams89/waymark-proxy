Geo-IP Lookups

Resolves visitor IP addresses into countries for country-based access rules, visitor statistics and the status page's visitor map. On a proxy that only serves your own network, turning this off saves the memory the database uses and a lookup on every request.


While off, the database is not loaded, statistics record no visitor countries, and access rules can't use country lists. IP and CIDR entries keep working.

Geo-IP Database Update

The Geo-IP database resolves visitor IP addresses into country codes for access control rules and statistics. Updating it keeps the country lookup results accurate.

When enabled, the database is refreshed once a week counting from the time Waymark was started, plus a random offset of up to 30 minutes. The randomized schedule prevents all Waymark instances (including those started by a cron job at a fixed time) from requesting the update server at the same moment.
