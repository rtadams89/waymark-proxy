ACLs

An ACL is an ordered list of rules, checked top down for the client's address: the first rule that matches allows, denies or drops the connection. An address no rule matches is denied. Each proxy rule uses one ACL (chosen in its editor, under Access); an ACL can be used by many proxy rules. Lists of addresses and countries can be kept as objects.

A new ACL has no rules, so it denies everything until you add some.
