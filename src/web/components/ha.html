High Availability

Run two Zoraxy instances as an active/passive pair. keepalived moves a floating IP to the healthy node with the highest priority; Zoraxy writes its settings and reports its health.

Notes

        

            
keepalived uses unicast VRRP between the listed node addresses. If a firewall sits between the nodes, allow IP protocol 112 (VRRP) between them.

            
keepalived runs only while high availability is on: turning it off here stops and disables keepalived on this node, and turning it on enables and starts it.

            
A node gives up the floating IP when Zoraxy's proxy listener stops answering (checked every 2 seconds; the floating IP moves within about 10 seconds), when Zoraxy stops, or when the machine goes down.

            
Only the active node renews certificates automatically. "Renew now" still works on any node.
