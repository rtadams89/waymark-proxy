Proxy Rules

HTTP rules share the HTTP(S) listener and are picked by host name: Waymark handles TLS, headers, authentication and caching for websites and web apps. TCP / UDP (Layer 4) rules each listen on their own port and forward the connection as it is, for anything that isn't HTTP. If you are only proxying for one host / domain, use Default Site instead.

Advanced Settings



Listen On

The address of this host the rule answers on, through the main HTTP(S) listener. Requests that arrive on another address are handled as if this rule did not exist (another matching rule, or the default site). This routes requests; to limit who can reach the site, use an ACL.

Additional Listening Addresses

Other addresses and ports this proxy rule also listens on, besides the main listening port (e.g. :8080 or 192.168.1.1:8080)

Enabled Destinations

Health-check URI (optional)
Path appended to the destination URL when the health check runs (e.g. /identity for Plex, /healthz). Leave empty to use /.
