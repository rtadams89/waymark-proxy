Welcome to the Waymark Proxy static web server

Your static web server is up and running

If you see this page, that means your static web server is running. By default, all the html files are stored under ./web/html/ relative to the Waymark runtime directory.

To manage your website files and customize error pages, use the WebDAV File Server feature in Waymark. You can see more details in the Static Web Server > WebDAV Server section of the Waymark admin panel.

Documentation: github.com/rtadams89/waymark-proxy.
